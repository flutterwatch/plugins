## How this differs from sqflite_darwin

sqflite_darwin is a method-channel plugin around FMDB. Method channels do
not run on watchOS, and FMDB is a wrapper the watch does not need, so this
package keeps none of that native code:

- `lib/src/sqlite3.dart` binds the part of SQLite's C API sqflite needs
  (`sqlite3_open_v2`, `_prepare_v2`, `_step`, the `_bind_*` and `_column_*`
  functions, `_changes`, `_last_insert_rowid`, `_get_autocommit`, the error
  calls). On the watch they resolve from the process, because
  `watchos/Package.swift` links the system `libsqlite3`; host tests open the
  macOS system library instead, so the same code runs real SQL there.
- `lib/src/handler.dart` answers sqflite's method protocol: the same
  methods, arguments and results the method channel carries on iOS, with the
  behaviour of sqflite_common_ffi, the protocol's reference implementation
  outside a method channel. That covers transaction ids (a call from outside
  the open transaction waits for it), `transactionClosed` when SQLite rolls a
  transaction back, paged cursors, batches with `continueOnError`, and
  single-instance databases.
- `watchos/Classes/sqflite_watchos_ffi.m` has two helpers: the Documents
  directory, and `sqlite3_libversion()`, which also keeps `libsqlite3` linked.
- sqflite federates through sqflite_common's default factory: `registerWith`
  sets `databaseFactoryOrNull` to a factory from sqflite_common's
  `buildDatabaseFactory`, as sqflite_darwin sets its method-channel factory.
  `buildDatabaseFactory` and `SqfliteDatabaseException` come from
  sqflite_common's `src/` libraries, which sqflite_common_ffi imports the
  same way; `sqflite_common: ^2.5.11` pins them.

The one API the port tool flagged, `UIDevice` (the platform version), is
replaced by `Platform.operatingSystemVersion`.

## Example

sqflite's own example app is built on `sqflite_example_common`, which is
not published, so `example/lib/main.dart` is a small watch demo instead.
`example/integration_test/sqflite_test.dart` is upstream's test, unchanged.

|---|---|
| `openDatabase` | ✅ read-write (creating parent directories) or read-only; single instance by path |
