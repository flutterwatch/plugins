rewritten by hand as an FFI implementation over `WKInterfaceDevice`.

## Status

✅ WORKING FFI implementation:

- `watchos/Classes/device_info_plus_watchos_ffi.m` exports one C function
  returning a JSON object shaped for `IosDeviceInfo.fromMap` (the map
  device_info_plus reads on an iOS-family platform; watchOS reports
  `Platform.isIOS == true`).
- `lib/device_info_plus_watchos.dart` extends `DeviceInfoPlatform`, resolves
  the symbol via `DynamicLibrary.process()`, and returns a `BaseDeviceInfo`.

## Notes

- `UIDevice` → `WKInterfaceDevice`: the whole reason the porter's stub could
  not stand — the watch has no UIKit device object.
- `modelName` has no marketing-name API on watchOS, so it falls back to the
  `uname()` machine identifier (e.g. `Watch7,1`).
- `availableRamSize` mirrors `physicalRamSize` — watchOS exposes no per-app
  available-memory API, and the field is non-nullable.
