## How this differs from the iOS implementation

flutter_local_notifications is not fully federated: its iOS implementation,
`IOSFlutterLocalNotificationsPlugin`, lives in the app-facing package, and
the app-facing calls check that the platform instance *is* one before using
it. The watch reports iOS as its target platform, so this package's class
extends `IOSFlutterLocalNotificationsPlugin` and overrides every method that
would use the method channel. That makes it depend on
`flutter_local_notifications` itself, which does not depend back on it.

The iOS plugin is the notification-center delegate. On the watch the
flutter-watchos host is (`FlutterWatchOSAppDelegate`), and it rebroadcasts
"will present" and "did receive response" as NSNotifications. The native
file observes them from a load-time constructor, so the tap that launched
the app, which the host does not keep, is caught before Dart runs; a tap
that arrives before `initialize` and before Dart reads the launch details
is the launch tap, later ones queue for the response callback. Each notification carries its id, payload and presentation flags in
`userInfo` under keys of this package's own, and callbacks for
notifications without them (pushes, other plugins) are left alone.

The port tool flagged `UIApplication` (badge clearing and opening settings
on iOS); neither exists on watchOS.

## Example

flutter_local_notifications' own example app is a phone demo that needs
`flutter_timezone`, which has no watchOS implementation, so
`example/lib/main.dart` is a small watch demo instead.
`example/integration_test/flutter_local_notifications_test.dart` is
upstream's test, unchanged but for the formatting this repo's CI checks.
`watchos_notifications_test.dart` next to it
checks what upstream's does not reach on the watch: the permission flags,
the launch details, and scheduling, listing and cancelling against the real
notification center. The cases that need permission ask for it only with
`--dart-define=FLNW_PROMPT=true`, when someone answers the prompt; without it
they are skipped and the suite asks for nothing, so it cannot hang.
