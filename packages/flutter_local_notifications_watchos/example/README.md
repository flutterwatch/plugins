# flutter_local_notifications_example

A watchOS-only example: show a notification now, schedule one ten seconds
out, and cancel them. Run it on an Apple Watch simulator with:

```sh
flutter-watchos run
```

`integration_test/flutter_local_notifications_test.dart` is
flutter_local_notifications' official integration test, unchanged. Its
first case asks for notification permission; answer the prompt on the watch
the first time it runs.
