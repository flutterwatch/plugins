Scaffolded by `flutter-watchos plugin port --from-pub battery_plus`. The
porter flagged four `UIDevice` regions (battery level/state and the battery
notifications) as disabled on watchOS — `UIDevice` does not exist on the
watch. This package is the hand-finished FFI implementation over the
`WKInterfaceDevice` equivalents.

## Status

✅ WORKING FFI implementation:

- `watchos/Classes/battery_plus_watchos_ffi.m` exports level / state / low-power
  readings from `WKInterfaceDevice` and `NSProcessInfo` (`used` +
  default-visibility; the CLI force-loads the archive, and `ffiSymbols`
  lists the exports).
- `lib/battery_plus_watchos.dart` extends `BatteryPlatform` and resolves the
  symbols via `DynamicLibrary.process()`.

## Notes

- `UIDevice.batteryLevel/batteryState` → `WKInterfaceDevice` equivalents;
  battery monitoring is auto-enabled on first read (the watch defaults it off).
- Battery reads are marshalled to the main thread (the properties are
  UI-adjacent).
- iOS delivers `onBatteryStateChanged` via `UIDevice` notifications; watchOS
  has no such notification, so the stream polls (default every 2s) and emits
  only on change. Tune via `BatteryPlusWatchos.pollInterval`.
